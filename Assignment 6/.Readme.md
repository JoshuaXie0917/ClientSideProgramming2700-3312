This program helps students track and analyze weekly expenses using JavaScript arrays.  
It uses map(), filter(), and reduce() to transform, select, and calculate expense data.


A callback function is a function passed into another function to run later.

In this project, map(), filter(), and reduce() use callback functions to process each expense item.  
They need callbacks because they must know what to do for each element in the array.
