## Project Description
This is a memo list app built with HTML, CSS, and JavaScript.  
Users can manage memos in different categories.
Users can:
- Use this app for study, work and life.
- add memo
- see the time for each memo
- complete a memo
- delete a memo
- finish a memo
- save data automatically
- back to homepage
