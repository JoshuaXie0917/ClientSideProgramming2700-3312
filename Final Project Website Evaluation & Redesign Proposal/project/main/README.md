# Final Project – Website Evaluation & Redesign

## Overview

This project analyzes the eCampus IT Programming website and proposes a redesigned version to improve usability, accessibility, and overall user experience.

## Problems Identified

The original website has several usability issues:
- Navigation is not clear for new users
- Important information is hidden in expandable sections
- Too much scrolling is required
- Visual design lacks hierarchy
- Accessibility features are limited

## Proposed Improvements

This project includes three redesign demos:

### 1. Navigation Improvement
- Sidebar layout for clearer structure
- Active section highlighting
- Easier navigation between sections

### 2. Content Organization
- Important information shown directly
- Card-style layout for better readability
-Reduced number of clicks

### 3. Accessibility Improvement
- Better color contrast
- Clear headings and buttons
- Improved readability and usability

## Technologies Used

- HTML (semantic structure)
- CSS (layout, spacing, visual design)
- JavaScript (interaction and dynamic updates)

## Why This Is Better

The redesigned version improves:
- User experience (easier to navigate)
- Accessibility (more inclusive design)
- Efficiency (less time to find information)
- Responsiveness (works on different screen sizes)

##Conclusion

This project demonstrates how small design improvements can greatly enhance usability and accessibility.

The new design provides a more user-friendly and efficient experience.
